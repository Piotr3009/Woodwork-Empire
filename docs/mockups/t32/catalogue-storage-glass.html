Each folder opened shows its one class card in the card every family wears, beside today's Timber racks folder: the name, Holds 40 glass units or Holds 200 glass units, the price, the delivery, the floor, and the empty picture box the catalogue shows while a class has no file, as the cutter sets showed it in Turn 28; no picture is drawn and none is asked for tonight.
